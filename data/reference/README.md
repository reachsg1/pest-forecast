# 참조 데이터

- `spots.json` — `python -m pipeline.cli spots` 가 농업기상 관측지점 API에서 받아 저장(라이브 모드 필수)
- `pests.csv` — 작물×병해충 마스터(모델 카드의 pest_id ↔ NCPMS 키 매핑용)
- `cultivation.csv` — 시군별 작물 재배면적(비재배지 판정용). 아래 참고
- `crop_calendar.yaml` — 권역·시도·시군별 작물 재배 기간(재배 시기 판정용). 파일 안 주석 참고

## 생물계절 판정 (pipeline/phenology.py)

작물이 재배되지 않는 지역이나 재배 기간이 아닌 날에는 위험지수를 내지 않고 **해당 없음**으로 발행한다.
'해당 없음'은 4단계 등급(정상·예보·주의보·경보)이 아니며, 등급별 지점 수 집계에서도 빠진다.

| 판정 | 근거 파일 | 조건 | 화면 표시 |
|---|---|---|---|
| 비재배지 | `cultivation.csv` | 지점 시군의 그 작물 재배면적 ≤ `config.MIN_CULTIVATION_HA` | 해당 없음 · 비재배지 |
| 재배 시기 아님 | `crop_calendar.yaml` | 그날이 가장 구체적인 구역의 재배 기간 밖 | 해당 없음 · 재배 시기 아님 |
| 판정 생략 | — | 해당 작물 자료가 파일에 없음 | 평소대로 위험도 표시 + `status.json` 경고 |

### cultivation.csv 만드는 법

컬럼: `year,sido,sigungu,crop,area_ha,source`

- `sido`는 정식 명칭(경기도)·약칭(경기) 모두 가능, `sigungu`는 시군 이름(수원시)
- `crop`은 `apple/rice/pepper` 또는 한글 품목명(사과, 벼·논벼, 고추·건고추)
- 같은 시군·작물이 여러 해 있으면 가장 최근 연도를 쓴다
- **한 작물이라도 행이 있으면 그 작물은 표에 없는 시군을 '비재배지'로 본다.** 전국 시군을 빠짐없이 넣을 것

권장 원천

1. **농업경영체 등록정보 – 농작물 재배현황**(농림축산식품부·농관원, uni.agrix.go.kr): 시도·시군 × 재배품목 × 노지/시설 재배면적, 2015~2025년. 노지 면적을 쓴다(사과·벼·노지고추 대상). 화면에서 내려받아 위 형식으로 정리
2. 공공데이터포털 '전체 노지작물 수확(재배) 현황정보'(data.go.kr 15151016): 시도·시군·읍면동 × 재배품목, 2019년 CSV. 1이 어려울 때 대안
3. 통계청 KOSIS 농작물생산조사: 시도 단위 검증용
