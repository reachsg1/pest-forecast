# DEM 지형 피처 효과 분석 (2026.11.12.)

국토지리정보원 한반도 90m DEM에서 만든 지형 피처가 NCPMS 시군 예찰 기반 발생 예측에 도움이 되는지, 예찰 자료가 있는 5개 병해충으로 검증했다.

- 피처 생성: `scripts/build_terrain_features.py` → `data/reference/terrain_sigungu.csv`(시군 230, 완경사지 통계 포함), `terrain_spots.csv`(관측지점 206)
- 검증: `pipeline/terrain_eval.py`(알고리즘별 지형 유무), `pipeline/terrain_control.py`(시군 이름표 대조·처음 보는 시군)
- 결과 파일: `data/survey/eval_<pest>_terrain.json`, `eval_<pest>_terrain_control.json`
- 모델: Random Forest(잎 최소 20, 배포 모델과 같음). 표기는 `전체 AUC / 같은 회차 AUC`

## 결과 요약

| 병해충 | 자료 | A 기본 | B +지형 | C +시군 평소 발생률(대조) | 처음 보는 시군 기상만 → +지형(같은 회차) |
|---|---|---|---|---|---|
| 고추 탄저병 | 2015~2025, 72시군 | 0.902/0.759 | 0.901/**0.789** | 0.899/0.759 | 0.563 → **0.592** |
| 고추 역병 | 2015~2025, 72시군 | 0.871/0.756 | **0.901/0.840** | 0.888/0.812 | 0.548 → **0.623** |
| 고추 담배나방 | 2015~2025, 72시군 | 0.896/0.788 | 0.899/**0.803** | 0.892/0.778 | 0.544 → **0.599** |
| 사과 탄저병 | 2021~2025, 25시군 | 0.907/0.744 | 0.920/0.842 | **0.929/0.876** | 0.330 → 0.403 |
| 사과 복숭아순나방 | 2021~2025, 25시군 | 0.868/0.859 | **0.928/0.922** | 0.907/0.899 | 0.377 → **0.242(악화)** |

A·B·C는 기상+직전 예찰 모델, 학습/시험 = 고추 2015~2022/2023~2025, 사과 2021~2023/2024~2025.

## 해석

1. **고추 3종: 지형이 일관되게 도움.** 세 병해충 모두 같은 회차 AUC가 올랐고(+0.015~+0.084), 시군 평소 발생률(이름표)보다 나았다(B > C). 학습에 없던 시군에서도 개선돼(+0.03~+0.075) 지형 조건 자체가 일반화되는 정보로 보인다.
   - 가장 큰 효과는 **고추 역병**(토양 전염·물 빠짐 영향이 큰 병) — 전체 AUC도 0.871 → 0.901.
   - 시군 발생률은 완경사지 고도가 낮을수록(탄저병 ρ=−0.30, 역병 −0.39, 담배나방 −0.36), 바다에 가까울수록(탄저병 −0.26, 역병 −0.42) 높았다.
2. **사과 2종: 판단 보류.** 개선 폭은 크지만 시군 이름표 대조군(C)과 비슷하거나 더 낮고, 처음 보는 시군에서는 복숭아순나방이 오히려 나빠졌다. 25개 시군·학습 3년으로는 지형이 '어느 시군인지'를 외우는 역할에 그칠 가능성이 크다. 2015~2020년 예찰을 더 받은 뒤 다시 검증한다.
3. **벼 3종: 미검증.** 예찰 자료 미수집.
4. 전체 AUC보다 **같은 회차 AUC**(같은 날 시군 간 위험 순위)에서 효과가 크다 — 지형은 날마다 변하지 않으므로 '같은 날씨에서 어느 시군이 더 위험한가'를 가르는 데 쓰인다.

## 주의
- 예찰은 시군 단위 → 시군 지형 요약(완경사지 평균)을 썼다. 실제 밭 위치(팜맵 등)를 알면 더 정확해질 수 있다.
- 지점별 예측(관측지점 206곳)에 쓰려면 지점 지형값(`terrain_spots.csv`)과 시군 요약 중 무엇을 넣을지 따로 검증이 필요하다(학습은 시군 요약으로 했음).
- 시험 연도가 고추 3년·사과 2년이라 해마다 효과가 달라질 수 있다.

## 토양 피처 추가 검증 (2026.11.12.)

토양특성 통계 V2(data.go.kr 15144796)로 예찰 78개 시군의 배수등급·유효토심·표토토성·경사·밭/과수/논 적성·주토지이용 면적 분포를 받아 13개 시군 토양 피처를 만들었다(`scripts/fetch_soil_stats.py` → `build_soil_features.py`, 원자료·피처는 공공누리 4유형이라 저장소 제외). 검증: `pipeline/static_eval.py` → `data/survey/eval_<pest>_static.json`.

해석
- **고추 3종**: 토양만 넣어도 지형과 비슷한 만큼 좋아진다(이름표 대조군보다 우수). 둘을 함께 넣어도 더 좋아지지 않는다 — 저지대·평탄지·배수 같은 정보가 겹치기 때문. 처음 보는 시군에서는 지형이 토양보다 약간 낫다.
- **사과 2종**: 토양 효과가 지형보다 크고, 처음 보는 시군에서도 토양은 개선(지형은 복숭아순나방에서 악화). 순열 중요도 상위에 유효토심(얕은 토양 비율)·과수/밭 적성이 올라옴 — 과수원 토양 조건이 의미 있을 가능성. 다만 25개 시군·학습 3년이라 2015~2020 예찰을 받은 뒤 재확인 필요.
- 결론: 지형·토양 모두 공통 피처로 두되, 모델에는 둘 중 하나(고추는 지형, 사과는 토양 우선)부터 넣고 비교하는 것이 합리적. 운영 지점 실행에 쓰려면 230개 시군 전체 토양을 받아야 함(약 2,000건, 일일 한도로 2~3일).
