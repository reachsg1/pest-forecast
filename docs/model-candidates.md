# 추가 예측 모델 후보 조사 (2026-11-10)

예측 지도에서 고를 수 있는 **두 번째 이후 모델**(`models/<작물>/<병해충>/variants/`) 후보를 문헌으로 조사한 결과입니다.
수치는 **열어 본 출처에 있는 값만** 적었습니다. 확인하지 못한 값은 "확인 못 함"으로 남겼고, 구현 전에 원문 대조와 담당 연구자 검토가 필요합니다.

- 확인 수준 표시: **원문** = 본문·표를 직접 확인 / **초록** = 초록·메타데이터만 / **2차** = 다른 논문·소프트웨어 소스·검색 요약에서만 확인
- 조사 당시 koreascience.kr 서버가 접속을 거부해 국내 학회지 PDF 상당수를 열지 못했습니다. 원문 확보가 필요한 목록은 맨 아래에 있습니다.
- NCPMS 자체 예측모형(사과탄저병 1000000032, 복숭아순나방 1000000006·1000000036, 고추탄저병 1000000007, 고추역병 1000000012, 담배나방1세대 1000000015, 잎도열병 1000000013, 잎집무늬마름병 1000000014)은 공개된 수식·모수 문서를 찾지 못했습니다. 담당 부서에 요청해야 합니다.

## 추천 순서

1. **사과 탄저병 — Magarey 일반감염모델**: 기존 A형에 그대로 들어가고 모수가 원문으로 완비돼 있습니다. 사과 과실에서 검증된 모델은 국내외 모두 없어(Quinn 외 2025), "딸기 탄저 모수 차용"이라고 화면에 밝혀야 합니다.
2. **벼 잎도열병 — BLASTAM**: 필요 습윤시간 표가 완비돼 있고, 기존 A형에 "직전 5일 평균기온" 조건만 추가하면 됩니다. 원 모형은 시간 자료로 습윤을 추정하므로 일 자료 근사라고 표시합니다.
3. **복숭아순나방 — Kim 외 2026**: 국내 사과원 1,087세트로 만들고 2024 독립자료로 검증한, 가장 근거가 강한 후보입니다. 식의 γ가 "나누기"로 인쇄돼 있는데 값(≈0.06)으로 보면 "곱하기"일 가능성이 있어 **저자 확인 후** 구현합니다.
4. **EPIRICE 한국판(도열병·잎집무늬마름병)**: 국내 보정판이 있고 일 자료로 돌아가지만, 감염–잠복–발병–소멸(SEIR) 구조라 새 모델 유형(`models/_base/seir.py`)이 필요합니다. 수치는 R 패키지 소스에서 읽은 값이라 논문 표와 대조가 필요합니다.

고추 3종은 바로 구현할 만큼 모수가 확보된 후보가 없습니다. PBcast·Kang 2010·신정욱 2011 원문을 확보하는 것이 먼저입니다.

## 1. 사과

### 1-1. 사과 탄저병 (*Colletotrichum* spp.)

**A1. Magarey 일반감염모델(GIM) + *C. acutatum* 모수** — 유형 A · 원문
- 필요 습윤시간 W(T) = Wmin / f(T), 단 W(T) ≤ Wmax
- f(T) = [(Tmax−T)/(Tmax−Topt)] · [(T−Tmin)/(Topt−Tmin)]^((Topt−Tmin)/(Tmax−Topt)), Tmin ≤ T ≤ Tmax 밖에서는 0. T는 습윤 중 평균기온
- 모수(딸기 과실 *C. acutatum*): Tmin 7, Topt 27.5, Tmax 35 ℃, Wmin 6 h, Wmax 36 h (원 논문에서 r=0.93, RMS 4.4 h)
- 노스캐롤라이나 주립대가 같은 모수로 딸기 탄저 위험 예보를 운영. 건조 4시간이면 감염기간 종료
- 확인 못 함: 마른 시간이 끼었을 때 이어 붙이는 기준(D50)의 *Colletotrichum* 값
- 출처: Magarey RD, Sutton TB, Thayer CL (2005) Phytopathology 95:92–100, doi:10.1094/PHYTO-95-0092 / https://ipm.ces.ncsu.edu/development-of-anthacnose-and-botrytis-strawberry-fruit-infection-risk-models

**A2. Ji 외 2021 포도 탄저(ripe rot) 감염률식** — 유형 A 변형 · 원문
- 감염률 = f(T) · f(WD)
  - f(T) = ((1.453+1)/1.453)^1.453 · (1/(1.453+1)) · exp((T−27.686)·0.520/(1.453+1)) / (1+exp((T−27.686)·0.520))
  - f(WD) = 1 − exp(−(0.065·WD)^3.321). 건조 3시간 이내는 연속 습윤으로 봄
- 국내 Yun & Park(1990, 한국식물병리학회지 6:219) 자료 일부로 맞춘 식. 포도 19사례에서 감염 횟수–발병률 ρ=0.878
- 출처: Plants 10:2288, doi:10.3390/plants10112288

**A3. Wilson 외 1990 로지스틱식(딸기, 플로리다 자문시스템)** — 새 유형 · 2차
- f = −3.7 + 0.33·LWD − 0.069·LWD·T + 0.005·LWD·T² − 9.3×10⁻⁵·LWD·T³, 감염 비율 = 1/(1+e^−f)
- 원 논문 Phytopathology 80:111–116 은 직접 보지 못함. 방제 기준(>0.15, >0.5; MacKenzie & Peres 2012 Plant Dis 96:522)도 검색 요약만 확인

참고(채택 비권장): Crusius 외 2002 사과 Glomerella 잎반점 모델(doi:10.1590/S0100-41582002000100010)은 사과 기주이지만 잎 대상이고 논문 안에서 최저·최고온도 값이 엇갈림. 서동민·이상환 2024 AI 모형은 계수 미공개.

### 1-2. 복숭아순나방 (*Grapholita molesta*)

**B1. Kim, Nah, Yang, Choi, Baek 2026 — 국내 사과원 4봉 모델** — 유형 B 확장 · 원문
- 적산: 1월 1일부터, 단일사인법, 하한 8.1 ℃·상한 32.2 ℃ (tmax·tmin으로 충분)
- 누적 성충 출현비율 f(x), x=DD:
  f(x) = α1/(1+(x/β1)^γ1) + α2/(1+exp[−(x−(β1+Δβ1))/γ2]) + α3/(1+exp[−(x−(β1+Δβ1+Δβ2))/γ3]) + α4/(1+exp[−(x−(β1+Δβ1+Δβ2+Δβ3))/γ4])
- 모수(Table 1): α1 0.2751, β1 172.23, γ1 −7.6149, α2 0.3501, Δβ1 464.08, γ2 0.0586, α3 0.1724, Δβ2 575.33, γ3 0.0904, α4 0.2024, Δβ3 604.38, γ4 0.0604
- 세대별 50% 출현 DD: 172.2 / 636.3 / 1211.6 / 1816.0
- 검증: 농진청 2013–2023 자료 1,087세트(r²=0.86), 2024 독립자료 55세트에서 예측일 오차 평균 6.75일(Kim 2004 방식 9.50일, Damos 방식 37.25일)
- **확인 필요**: γ2~γ4가 분모로 인쇄돼 있으나 그대로면 계단함수에 가까움 → 곱셈 여부 저자 확인. 본문은 "Weibull"이라 하나 식은 log-logistic+logistic
- 출처: PLOS ONE 21(4):e0347667, doi:10.1371/journal.pone.0347667

**B2. Kim, Boo, Jeon 2004 — 수원 복숭아원 고정 DD 창** — 유형 B · 초록+2차
- 1월 1일부터 약 39 DD에 첫 성충(기점), 기점 이후 세대별 성충 최성기 98 / 620 / 1233 / 1916 DD
- B1 논문은 이 연구를 102.3 / 628.3 / 1369.9 / 1876.0 DD로 인용 → 기산점 차이 가능, 원문 대조 필요. 발육영점 8.1 ℃는 B1의 인용으로만 확인
- 출처: 한국응용곤충학회지 43(4):281–289, https://db.koreascholar.com/Article/Detail/9961

참고: Borchert 외 2004(미국, 7.2/32.2 ℃, 2세대 산란 시작 기점 후 507 DD; doi:10.1603/0022-0493-97.4.1353, 초록만), Ahn·Choi·Kho 2016(봄 첫 발생, 8.14 ℃·279.3 DD, 학회 초록, 적산 시작일 확인 못 함).

## 2. 고추

### 2-1. 고추 탄저병

**P1. 신정욱·윤성철 2011 일별 감염위험도** — 유형 C 유사(선형 점수+임계값) · 2차
- IR = (일평균기온 − 16) × 0.07 + 일강우량 × 0.11, IR ≥ 3 이면 위험(NCPMS 서비스 기준으로 소개됨)
- 시간별 부착기 형성식을 일별로 단순화한 식으로 소개됨. 16 ℃ 미만 음수 처리 방식 확인 못 함
- 식은 2014 농림기상학회 학술대회 자료의 검색 요약에서만 확인. 원 논문: Shin J, Yun SC (2011) 한국농림기상학회지 13(1):10–19, doi:10.5532/kjafm.2011.13.1.010

**P2. Kang, Yun, Park 2010 비선형 로지스틱 감염모형** — 유형 A 변형 · 초록
- 부착기 형성률 = 로지스틱(A, B, k). A는 효소반응 평형모형, B·k는 역수 모형으로 온도의 함수. 선형모형은 필요 습윤시간을 짧게 예측
- 모수 확인 못 함. 출처: Plant Pathol J 26(1):17–24, doi:10.5423/PPJ.2010.26.1.017
- 포장 검증: Ahn 외 2008(Plant Pathol J 24(1):46–51, doi:10.5423/PPJ.2008.24.1.046) — IR>3 살포로 관행 10·8회 → 3·3회, 이병과율 차이 유의하지 않음. 10 km 떨어진 기상대 자료로는 위험도 과소

### 2-2. 고추 역병

**P3. PBcast (Do, Kang, Park 2012)** — 새 유형(과정 기반) · 초록
- 구성: 지온 함수의 유주자낭 형성 + 토양수분 추정 + 토양 내 활성 접종원량. 입력은 일 기온·습도·강우와 지역 토성
- 출력 IR = 직전 3일 활성 접종원 누적량, 224 이상이면 1차 감염일(190 자료세트), 첫 발병은 추정 감염일 8±3일 뒤, 독립 검증 6건 중 5건 적중
- 하위모형 식·계수 확인 못 함. 출처: Plant Pathol J 28(2):172–184, doi:10.5423/PPJ.2012.28.2.172
- 후속: Ahn 외 2020 Res Plant Dis 26(4):229, doi:10.5423/RPD.2020.26.4.229 — IR 200/224 살포 기준 비교, 관행 대비 3~4회 감축(검색 요약)

참고(보류): Liu 외 2008(중국, doi:10.1007/s11703-008-0010-x) 지온·토양수분 회귀식은 지온 입력이 없고 PDF 부호 해독에 의문이 있음. PEPBLIGHT(2001, 한국농림기상학회지)는 저자·식 확인 못 함.

## 3. 벼

### 3-1. 벼 잎도열병

**R1. BLASTAM (越水 1988)** — 유형 A · 원문(広島県 설명자료)
- 감염 필요 습윤시간(습윤 중 평균기온별): 15℃ 17h, 16℃ 15h, 17℃ 14h, 18℃ 13h, 19℃ 12h, 20℃ 11h, 21℃ 11h, 22~25℃ 10h
- 판정: 호적 = 습윤 중 평균기온 15~25 ℃ + 위 표 이상 습윤 + 직전 5일 평균기온 20~25 ℃. 준호적 1~4(5일 평균 <20 또는 ≥25, 습윤 중 기온 범위 밖, 습윤 부족). 습윤 10 h 미만은 비해당. 발병은 호적일 약 7일 뒤
- 일 자료 한계: 원 모형은 시간자료(기온·강수·일조·풍속)로 습윤을 추정(규칙 확인 못 함). 우리 lwd_hours 추정치와 tavg 근사
- 출처: https://www.pref.hiroshima.lg.jp/uploaded/attachment/535771.pdf, 원전 越水幸男 1988 東北農試研報(권·쪽 확인 못 함). 한국 검증 확인 못 함

**R2. EPIRICE 한국판 (Kim, Cho, Lee, Lee 2015)** — 새 유형(SEIR) · 2차
- 입력 일 tavg·rh·rain. 젖은 날 = RH ≥ 90 또는 강우 ≥ 5 mm
- 일 감염률 Rc = RcOpt × RcA(이앙 후 일수) × RcT(tavg) × RcW
