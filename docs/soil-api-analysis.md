# 토양 API 활용 가능성 분석 (2026.11.12.)

## 1. 신청한 API: 농촌진흥청 국립농업과학원_토양도 기반 토양특성 상세 정보 V3 (data.go.kr 15144225)

- 호출: `https://apis.data.go.kr/1390802/SoilEnviron/SoilCharac/V3/getSoilCharacter?serviceKey=…&PNU_CD=<19자리>` — **현재 `DATA_GO_KR_KEY`로 정상 응답 확인**(예시 PNU, 결과코드 200)
- 입력: **PNU(필지 고유번호) 19자리만** = 법정동코드 10 + 산 여부 1 + 본번 4 + 부번 4. 좌표·주소로는 조회 불가
- 출력(XML, 필지 1개당 27항목, 모두 **숫자 코드**):

| 구분 | 항목(응답 태그) |
|---|---|
| 물리성 | 배수등급(Soildra_Cd), 유효토심(Vldsoildep_Cd), 표토토성(Surtture_Cd), 표토자갈함량(Sur_Ston_Cd), 침식등급(Erosion_Cd), 구조(Soil_Structure_Cd), 토색·심토색 |
| 생성·분류 | 모재(Matrix_Cd), 분포지형(Soil_Type_Geo_Cd), 퇴적양식(Accu_Style_Cd), 토양목·아목·대군, 토양유형 |
| 이용 | 주토지이용(Main_Landuse_Cd), 토지이용추천 |
| 적성 | 논·밭·과수상전·초지·임지 적성등급과 저해요인 |

- 코드 뜻: data.go.kr 첨부 'OPEN API기술명세서_토양도 기반 토양특성 상세정보V3_ver1.0.hwp'(원본은 저장소 밖 `참고자료/토양특성 상세정보 V3 기술명세서/`)의 3.1 코드표 27종을 **`data/reference/soil_codes.json`**(응답 태그 → 코드 → 이름)으로 옮김. 순서형 항목: 배수등급 01 매우양호~06 매우불량, 유효토심 01 매우얕음(0–25cm)~04 깊음(100cm 이상), 침식등급 01 없음~04 매우심함, 적성등급 01 1급지~05 5급지, 99 = 기타
  - 예시 필지(5115034022100750001) 해석: 배수 약간양호, 유효토심 보통(50–100cm), 표토 양질사토, 주토지이용 논, 밭 적성 2급지
- 라이선스: 공공누리 **제4유형(출처표시·상업적 이용금지·변경금지)**. 모델 입력으로 쓰는 것은 가능하나, 값을 가공해 재배포·화면 게시할 때는 출처 표시와 변경금지 조건을 검토해야 함

## 2. 병해충·작물 생육과의 관련(왜 쓸 만한가)

- **배수등급·유효토심·토성**: 토양 수분 → 뿌리 병(고추 역병·풋마름병), 습해, 가뭄 스트레스. 지형 분석(`docs/terrain-analysis.md`)에서 지형 효과가 가장 컸던 병이 고추 역병(토양 전염·물 빠짐)이라 토양 배수 정보가 추가로 설명력을 줄 가능성이 높다
- **밭·과수 적성등급, 저해요인**: 재배 적지 여부 → 작물 생육 기반 조건
- **주토지이용**: 지점 주변이 실제 밭·논·과수원인지 확인(재배 여부 판정 보완)

## 3. 지금 구조에 붙일 때의 걸림돌

1. **PNU 변환**: 관측지점 206곳 중 지번 주소는 115곳뿐, 나머지는 도로명 주소 → 법정동코드표 + 도로명→지번 변환(주소 API) 또는 좌표→필지 변환(팜맵·브이월드)이 필요
2. **대표성**: 관측지점 필지(농업기술센터 부지 등)의 토양 ≠ 주변 밭 토양. 우리 예측·학습 단위(관측지점·시군 예찰)와 '필지 1개' 값이 맞지 않음
3. ~~코드표 미확보~~ → 확보 완료(`data/reference/soil_codes.json`)
