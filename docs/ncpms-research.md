# NCPMS 활용 조사와 대상 확대안 (2026-11-10)

출처: NCPMS OpenAPI 안내(`ncpms.rda.go.kr/npms/OpenApiInfo.np`)와 각 서비스 상세 명세, NCPMS 병해충예측지도·예찰결과 화면, 공공데이터포털.
원자료: `data/reference/ncpms_forecast_models.csv`(예측모형 51개), `data/reference/ncpms_survey_targets.csv`(예찰 대상·코드).

## 1. NCPMS OpenAPI가 실제로 주는 것

| 묶음 | 서비스(코드) | 형태 | 우리에게 쓸모 |
|---|---|---|---|
| 병해충검색 | 병 검색 SVC01 / 병 상세 SVC05, 해충 검색 SVC03 / 해충 상세 SVC07 외 병원체·곤충·잡초·천적·이미지·통합검색 등 16종 | XML/JSON 원자료 | 방제 정보 탭(발생생태·증상·방제법·사진), 병해충 마스터 |
| 병해충예측 | 예측지도 SVC31, 지점자료예측조회 SVC32, 예측조사비교 SVC33, 벼도열병 방제결정지원 SVC34 | **지도 위젯**(proxyUrl·div_id, 인증 도메인 필요) — 수치 원자료 아님 | 상세 화면에 NCPMS 공식 예측을 나란히 끼워 넣기(비교용) |
| 병해충예찰 | 예찰 검색 SVC51 → 시도별 SVC52 → 시군구별 SVC53 | XML/JSON 원자료 | **모델 검증 정답**(회차별 시도·시군구 조사값) |
| 병해충상담 | 검색 SVC41, 상세 SVC42 | 원자료 | 해당 없음 |

- 검색·예찰 계열은 `serviceType`(AA001 XML / AA003 JSON)이 필수. 기존 코드가 빠뜨리고 있어 수정함.
- **'병해충 발생정보'(예보·주의보·경보 발령)는 OpenAPI에 없다.** 웹 게시판(`/npms/NewIndcUserListR.np`)으로만 공개 → 필요하면 담당 부서에 데이터 제공 요청.
- 예측 위젯은 OpenAPI 신청 시 등록한 도메인에서만 동작(ERR_105). 배포 도메인이 정해진 뒤 신청.

## 2. NCPMS 자체 예측모형: 9개 작물 51개

논벼 4(잎도열병, 잎집무늬마름병, 세균벼알마름병 2) · 사과 17(탄저병, 갈색무늬병, 겹무늬썩음병, 검은별무늬병, 복숭아순나방 등) · 배 14(검은별무늬병, 붉은별무늬병, 복숭아순나방 등) · 고추 7(탄저병, 역병, 세균성점무늬병, 풋마름병, 담배나방1세대, 꽃노랑총채벌레, 파밤나방) · 감귤 5 · 감자 1(역병) · 포도 1(노균병) · 파 1(파밤나방) · 마늘 1(고자리파리).

## 5. 대상 확대안

선정 기준(제안): ① NCPMS 예찰이 있어 **검증 가능**, ② NCPMS 예측모형이 있어 **비교 기준** 있음, ③ 기상 의존성이 커서 모델화 가능, ④ 재배면적이 커서 수요 큼.

**1순위 (①②③ 모두 충족, 기존 작물)**
- 사과: 갈색무늬병, 겹무늬썩음병, 붉은별무늬병(예찰만)·점무늬낙엽병(예찰만)
- 고추: 세균점무늬병, 풋마름병, 총채벌레류
- 벼: 세균벼알마름병, 이삭도열병(예찰만)

**2순위 (새 작물, NCPMS 예측모형 있음)**
- 배(검은별무늬병, 붉은별무늬병, 복숭아순나방), 감귤(검은점무늬병, 궤양병, 더뎅이병), 포도(노균병), 마늘(고자리파리), 감자(역병)

**3순위 (예찰만 있음 — 검증용 정답은 있으나 비교 모형 없음)**
- 복숭아(탄저병·세균구멍병), 감(탄저병), 배추·무(노균병·무름병), 양파(노균병), 보리(붉은곰팡이병), 콩(담배거세미나방), 옥수수(열대거세미나방)

※ 새 모델의 파라미터는 근거 문헌과 담당 연구자 검토 없이 만들지 않는다(CLAUDE.md). 확대는 모델 폴더 골격 + `status: draft` + TODO로 시작.

## 6. 지점 기준 개선안

1. **입력 기상**: 농업기상 관측소(현행 유지) — 위험도 계산의 기본 단위.
2. **검증**: NCPMS 예찰(SVC51~53)의 시군구 조사값 ↔ 같은 시군의 관측소 예측을 비교(백테스트 `survey.csv` 자동 생성 가능).
3. **포장 단위 검증**: 조사지점현황(15123424) 좌표로 관측소 최근접 매칭(거리·고도차 임계).
4. **화면**: 관측소 마커 + 설계서 S02의 **시군 단위 표시**(예찰·재배면적과 같은 단위)를 추가.
